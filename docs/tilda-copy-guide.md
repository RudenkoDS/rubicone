# Как скопировать лендинг Rubicone в Tilda, Pitch и Git

Этот файл объясняет, как использовать файл `index.html`, который находится в корне проекта, и чем отличаются сценарии «вставить код в Tilda», «поделиться кодом через Pitch» и «загрузить код в Git».

## 1. Вставка в Tilda

1. Откройте нужный проект в Tilda.
2. Создайте новую страницу или перейдите на существующую.
3. Добавьте блок **«Т» → «HTML»** (в разделе «Другие» он называется *«Zero Block → HTML»*).
4. Скопируйте весь код из `index.html` — от `<!DOCTYPE html>` до `</html>`.
5. Вставьте код в окно HTML-блока Tilda.
6. Нажмите «Сохранить и закрыть», затем опубликуйте страницу.

> **Важно:** если в Tilda уже есть другие блоки, убедитесь, что стили Rubicone не конфликтуют с глобальными стилями страницы. При необходимости оставляйте Rubicone как отдельную страницу.

## 2. Добавление в Pitch

Pitch — это сервис для презентаций. Вставить полноценную HTML-страницу внутрь Pitch нельзя, но можно:

- Создать слайд и вставить **фото или скриншоты** лендинга.
- Вставить **фрагменты кода** в виде текста через блок «Code Snippet».
- Добавить **ссылку** на живую страницу (например, размещённую в Tilda или на GitHub Pages).

Алгоритм работы с кодом Rubicone для Pitch:

1. Сделайте скриншоты ключевых блоков лендинга или используйте встроенные картинки.
2. Добавьте на слайд ссылку на опубликованную страницу (Tilda, Netlify, GitHub Pages и т.д.).
3. Если нужно показать кусок кода, выделите его из `index.html` и вставьте как текстовый блок «Code».

## 3. Публикация в Git

Git нужен для контроля версий и совместной разработки. Чтобы загрузить код Rubicone в GitHub или другой Git-репозиторий:

1. Инициализируйте репозиторий (если нужно):
   ```bash
   git init
   git add index.html docs/
   git commit -m "Add Rubicone landing"
   ```
2. Создайте новый репозиторий на GitHub и скопируйте URL.
3. Добавьте удалённый репозиторий и запушьте изменения:
   ```bash
   git remote add origin https://github.com/username/rubicone-landing.git
   git push -u origin main
   ```
4. Поделитесь ссылкой на репозиторий или подключите GitHub Pages для публикации.

## 4. В чём разница между Tilda, Pitch и Git?

| Платформа | Для чего подходит | Что можно сделать с `index.html` |
|-----------|-------------------|----------------------------------|
| **Tilda** | Быстрый запуск лендинга без программирования | Вставить целиком в HTML-блок, страница будет работать и отображаться как сайт |
| **Pitch** | Презентации и питчи для клиентов/команды | Показывать скриншоты, кодовые фрагменты или ссылки, но не запускать сам сайт внутри Pitch |
| **Git**   | Хранение кода, командная разработка, автодеплой | Загружать файл в репозиторий, отслеживать версии, подключать автоматический деплой |

Используйте Tilda, если нужно быстро показать рабочий лендинг; Pitch — если готовите презентацию с иллюстрациями и ссылками; Git — если важен контроль версий, совместная работа и публикация через GitHub Pages или CI/CD.
